# Contributing to Deetage Studio

Thank you for your interest in contributing to **Deetage Studio Pvt Ltd**.

We welcome constructive feedback, bug reports, feature suggestions and improvements that help make our projects better.

## 🐛 Reporting Bugs

Before submitting a bug report, please check whether the issue has already been reported.

When reporting a bug, include:

* A clear description of the problem
* Steps to reproduce the issue
* Expected behaviour
* Actual behaviour
* Browser and device information
* Screenshots or relevant logs, if available

## 💡 Feature Requests

Feature suggestions are welcome.

Please explain:

* What problem the feature would solve
* How the feature would improve the project
* Any proposed implementation or examples, if relevant

## 🔀 Pull Requests

Before submitting a pull request:

1. Make sure your changes are relevant to the project.
2. Keep changes focused and easy to review.
3. Test your changes before submitting.
4. Ensure existing functionality is not unnecessarily affected.
5. Provide a clear description of what was changed and why.

## 🧹 Code Quality

Please aim to maintain:

* Clean and readable code
* Consistent formatting
* Meaningful naming
* Responsive UI
* Accessibility best practices
* Performance-conscious implementation
* Secure development practices

## 🔐 Security Issues

Please **do not report security vulnerabilities through public GitHub Issues**.

For security-related concerns, please follow our [Security Policy](./SECURITY.md).
