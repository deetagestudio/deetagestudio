# Security Policy

## 🔐 Security at Deetage Studio

At **Deetage Studio Pvt Ltd**, we take the security of our software, websites and digital products seriously.

We continuously work to identify and address potential security issues and follow modern security best practices throughout development and deployment.

## 📦 Supported Versions

This project is actively maintained. Security fixes will be applied to the current production version and, where reasonably possible, to actively maintained releases.

| Version          | Supported          |
| ---------------- | ------------------ |
| Current / Latest | :white_check_mark: |
| Older versions   | :x:                |

## 🚨 Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it responsibly.

Please **do not publicly disclose the vulnerability** before we have had an opportunity to investigate and address the issue.

Report security vulnerabilities by email:

**📧 [deetage.studio@gmail.com](mailto:deetage.studio@gmail.com)**

When reporting an issue, please include:

* A clear description of the vulnerability
* Steps required to reproduce the issue
* The potential impact
* Relevant screenshots, logs or proof-of-concept details, if available
* Any suggested mitigation, if applicable

We will review legitimate security reports and take appropriate action based on the severity and impact of the issue.

## 🤝 Responsible Disclosure

We appreciate responsible security researchers and contributors who help us improve the security of our projects.

Please allow reasonable time for investigation and remediation before publicly disclosing any vulnerability.

Thank you for helping us keep **Deetage Studio** and its users secure.
